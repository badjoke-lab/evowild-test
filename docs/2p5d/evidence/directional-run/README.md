# EvoWild Run 周回レースの8方向走行

[ゲーム本体をダウンロード](./EvoWild-Run.zip)。展開後に `python3 start.py`（Windows は `py start.py`）を実行し、ホームからコース・出走個体・Agent設定を選ぶ。画面右上のカメラ選択はレース中も一時停止中も使える。ZIPには同じゲーム本体、画像、ローカル起動用のPython標準ライブラリのスクリプトを収録した。リポジトリからは `npm install` 後に `npm --ignore-scripts run dev` を起動し、`/evowild-test/game-2p5d.html` を開く。

## 画質判定と残課題

**REVISE（最終画質は未承認）。** P/E/Aの非側面は元の1セルが36×48pxで、拡大すると脚先・尾・Cue Bandの細部が潰れる。特にPの胸下とAの斜めの足先は、遠近2本の脚を分離して読み取りにくい。列境界をまたぐ原画の欠損は一部のキーの再使用で避けており、12コマすべてが独立した原画ではない。

Sの後方斜めは2D合成で、横向きの原画に比べて頭と骨盤のつながりが硬い。軸方向で手前の脚が奥の脚を隠す区間もある。S/E/A側面には6枚のポーズ間の跳びが残る。左右の鏡像による光の向きと模様の反転、レーン変更時の足滑り、実機上のフレームレートは今後の確認項目。

## レース本体での確認

PC動画は同じ出走個体Micaの通常レース。改修前は `bb5f97aa` のゲームを使用した。25fps、各40msのブラウザー時計の進行後に1100×660のページ全体を1回撮影した。改修前後は各475枚、カメラ切り替えは550枚。キャラクターの合成や映像間の補間は行っていない。モバイル動画はPixel 7エミュレーションでSereinが出走したレースをPlaywrightで実時間録画した。端末実機の測定は未実施。

PC・モバイルともホーム直線、第1コーナー、向正面、最終コーナーを通過した。スタート時に18体を描画。PCの別の通し録画では743m付近で選択個体が11位から10位へ、1332m付近で10位から9位へ上がり、最終順位は8位だった。モバイルでは序盤の13位から12位に上がり、そのまま完走した。各サンプルに距離、順位、方向、Agent判断回数を収録した。[PC実画面](./after.jpg) · [モバイル実画面](./mobile.jpg) · [観測値](./observations.json)

検証範囲は周回路、カメラ8方向、位相保持、Race Agent、レーン変更の由来、着順、ホームからレース・保存・履歴再読み込みまで。ZIP版もローカルHTTPで起動し、外部通信0件で18体分の順位と再読み込み後の履歴を確認した。ソース一式の3D関連テストや端末固有の性能評価は対象外。
