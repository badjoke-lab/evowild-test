# D3-C v2: 軽量スプラット風描画 E/F（実装候補・未計測）

既存 A–D および旧証拠は保持。S GLB、骨格、IK、走行、背景、当たり判定には変更なし。
公開説明（https://x.com/asobodesign ）から着想した独立実装であり、投稿者の具体的なソースの再現ではない。
E は既存 C の不透明点に等方的なガウス濃淡を追加。D の共分散投影・浮動小数点合成・深度専用パスは使用しない。
F は E と既存スキンメッシュを同一の低解像度パスで深度テストし、空隙補完を試す。小さなクリップ深度バイアスによる点の浮き・交差も評価する。
背景は従来と同じメッシュのピクセル後処理であり、全面のプロシージャル粒化は未実装。

## 検証
Vite 起動後、`node scripts/pixel-art-evidence.mjs all` を実行。
従来の証拠と分離し `docs/evidence/pixel-art/lightweight-v2/` に6方式・4個体数の結果を保存。
個体数 1/10/50/100、同じカメラ位相・密度・解像度で比較。各方式120フレームと同期動画、接地監査、PC/Pixel 7エミュレーションを含む。
E は C と脚先の明滅・輪郭・GPU時間を比較。F は C/E と脚先・角の空隙、交差、レース距離の視認性を比較。実機は別計測。
実装時点ではビルド・ブラウザ・画質・性能の実測未実施。採用判定は保留。main への統合不可。
