# Lane 4 third-party technique note

This lane intentionally borrows a proven pseudo-3D road rendering technique instead of inventing the projection system from scratch.

Reference implementation:
- Jake Gordon, "JavaScript Racer"
- Repository: https://github.com/jakesgordon/javascript-racer
- Code license: MIT

Policy for EvoWild Run Lane 4:
- projection math / segmented-road technique may be adapted under MIT
- no OutRun-derived sprite sheets, background art, sound effects, music, logos, or other copyrighted game assets are copied
- the S creature run sheet used here already exists inside the EvoWild test project history
- environmental graphics in Lane 4 are procedural canvas graphics made in this repository

This file exists so the source boundary is explicit.
