# EvoWild Run — S v8 Correction Lock

Status: **ACTIVE / S ONLY / v7 REJECTED**

This document supersedes any earlier visual acceptance of the current S candidate.

## Decision

The current S candidate (v7) is **rejected as a production candidate**.

It does not sufficiently match the repository reference sheet. Do not rig it, animate it, propagate it to P/E/A, or treat it as the base species model.

It may remain only as a technical artifact showing what not to do.

## Why v7 fails

### 1. Overall body silhouette

Reference S:
- compact athletic torso;
- pronounced shoulder and pelvic masses connected by a narrow waist;
- arched / tensioned dorsal line;
- body depth concentrated around shoulder and pelvis;
- rear body tapers into a distinct tail root.

v7:
- long nearly horizontal capsule / beam;
- insufficient shoulder-to-waist-to-pelvis articulation;
- silhouette reads as one stretched shell rather than an athletic quadruped.

Correction:
- shorten the visual trunk;
- deepen shoulder mass;
- define a narrow waist;
- make pelvis a clear but connected rear mass;
- preserve one continuous organism rather than separate blobs.

### 2. Head / neck

Reference S:
- small wedge-like head;
- clearly readable jaw / throat;
- neck is narrow and angled into the shoulder;
- head remains visually separate from the crest.

v7:
- head and neck merge into a long triangular wedge;
- throat / jaw definition is weak;
- the head reads more like a nose on the end of a shell.

Correction:
- shorten head;
- restore visible jaw / throat break;
- narrow the neck;
- connect neck into the shoulder rather than extending the whole torso forward.

### 3. Crest

Reference S:
- two long rearward blades;
- narrow at the tips;
- clearly rooted in the skull / rear head;
- elegant directional line;
- does not dominate total body mass.

v7:
- crest is too massive and too thick;
- it dominates the upper silhouette;
- root feels like a separate hard attachment.

Correction:
- reduce crest thickness and volume substantially;
- keep length but taper aggressively;
- root it into skull / upper neck;
- match the reference's clean rearward sweep.

### 4. Shoulder / chest

Reference S:
- visible structural shoulder;
- front limb emerges from a designed shoulder mass;
- chest narrows into the waist.

v7:
- shoulder pad is a surface patch on a long body;
- front limb appears inserted into the underside of the torso.

Correction:
- create a real shoulder mass;
- make scapular / shoulder plane part of the body silhouette;
- front limb root must feel structurally supported.

### 5. Forelimbs

Reference S:
- upper limb, elbow, lower limb, wrist and foot are visibly differentiated;
- slim but not stick-like;
- feet are small, split / claw-like and directional.

v7:
- long dark tubes with weak anatomical hierarchy;
- knee / elbow relationships read generically;
- feet are too simple.

Correction:
- build a clear upper-limb wedge / cylinder transition;
- make elbow and wrist readable;
- distal limb narrows;
- split foot / toe shape must match reference language.

### 6. Hind limbs

Reference S:
- hind limb is not a copy of the forelimb;
- strong thigh / hip origin;
- clear hock-like backward angle;
- rear foot reaches back with a distinct recovery geometry.

v7:
- fore and hind limbs are too similar;
- hindquarter power structure is missing.

Correction:
- larger upper hind mass at pelvis;
- more obvious backward hock geometry;
- different proportions from front leg while keeping the same species design language.

### 7. Tail

Reference S:
- tail is a distinct slender balancing appendage;
- emerges clearly from the rump;
- drops / flows backward;
- does not look like the whole body tapering into a point.

v7:
- rear torso itself tapers into a long point;
- tail is not sufficiently separate from the body.

Correction:
- end pelvis / rump first;
- then start a narrower tail from a defined root;
- tail should remain slender and flexible.

### 8. Surface / armor language

Reference S:
- light dorsal plates and darker understructure describe muscle / structure;
- panel breaks follow anatomy.

v7:
- large smooth white body dominates;
- panels feel applied to a shell rather than integrated with anatomy.

Correction:
- use surface plates to reinforce shoulder, spine, pelvis and limb structure;
- avoid one large white capsule.

### 9. Cue Band

Reference:
- compact head-mounted device;
- sits around / beside the skull;
- readable but secondary.

v7:
- current lights / modules are too visually detached from the final intended head architecture.

Correction:
- fit Cue Band only after the corrected head is stable;
- device must conform to skull and crest root;
- do not use it to hide head-shape problems.

## Locked v8 target proportions

These are visual constraints, not exact engineering dimensions:

- head: small relative to torso; visibly smaller than v7;
- crest: long but much thinner than v7;
- torso: shorter than v7, with more shoulder / pelvis definition;
- waist: clearly narrower than shoulder and pelvis;
- front leg: long, slim, multi-stage;
- hind leg: long, more powerful upper section and stronger rearward hock angle;
- tail: separate, narrow appendage; not a continuation of the torso shell;
- body height: athletic / elevated, but not stilt-like.

## v8 work order

1. delete / ignore v7 torso proportions;
2. rebuild torso silhouette first;
3. rebuild head + neck;
4. rebuild crest;
5. rebuild forelimb;
6. rebuild hind limb separately;
7. rebuild tail root + tail;
8. fit Cue Band last;
9. check SIDE;
10. check FRONT;
11. check 3/4 FRONT;
12. check REAR;
13. check 3/4 REAR;
14. check LOW 3/4.

## Hard stop

Do not proceed beyond S until v8 is materially closer to the reference in SIDE silhouette.

If SIDE still reads as:
- long shell;
- shrimp / crustacean;
- insect-like;
- generic quadruped;
- floating crest;
- tube legs;

reject it and revise again.
