## 制作方法の変更

v4 の構築ヘルパーや v6 の球体・ロフト・ボクセル合成を再実行せず、v6 の `.blend` から開始した。
既存の胴・四肢形状を新ファイル内で置き換え、胸、肩、上腕、前腕、腹、後肢を共有頂点のポリゴンパッチから作り直した。
肩と骨盤の開口境界を四肢へ延長し、胸と肩の表面が上腕へ連続する構造にした。
胸の前向きの面と肩・上腕の斜めの面を制御点で編集し、細分化した同じ面へ筋肉境界のストロークを投影して凹みを刻んだ。
独立した筋肉シェルは追加していない。これは Blender Python による明示的なメッシュ編集であり、手操作のスカルプト作業を行ったとの主張ではない。

頭・口吻・冠・Cue Band・指はv6の実メッシュを編集して保持。頭を高くし、口吻を短縮、手首の球状キャップを平たくした。
尾は新しい閉じたポリゴンケージに置換した。側面確認で生じていた尾根元の見かけ上の隙間を修正し、最終GLBから全方向を再レンダリングした。
`.blend` には未変更の正規画像、編集可能な粗いケージ、実スカルプト面、5方向カメラ、照明を保存している。

## 部位別の実画像判定

| 部位 | v6からの変化・正規画像との差 | 判定 |
|---|---|---|
| 胸→肩→上腕の接続 | 共有トポロジーと斜めの面の連続は成立。関節付近の独立した部品感は減った。ただし接続成立だけでは筋肉構造の一致にならない。 | 構造のみ KEEP / 造形 REVISE |
| 胸・胸筋 | 胸を高くしたが、FRONTでは大きな一枚の胸当てのように見える。正規画像の左右の胸筋と斜めの下胸部の重なりが足りない。この点はv6から十分改善していない。 | REVISE |
| 肩・上腕 | 肩から肘までの連続した赤・灰の面を作ったが、肩はまだ滑らかで、上腕の長い赤い帯が目立つ。正規画像の丸みと角度を併せ持つ筋肉の量感・境界に不一致。 | REVISE |
| 胴体比率・背中 | 頭より高いv6のこぶ状の印象は減った。反面、SIDE/REAR34では背中から腰が滑らかな一続きの斜面で、正規の肩甲部・脇腹の分節が不足。 | REVISE |
| 頭・口吻 | 胸との高さ関係と短い口吻の方向は改善。頬・顎・目周囲の具体的な輪郭は簡略化が残る。 | REVISE |
| 冠・Cue Band | 後方へ流れる冠と小さなCue Bandを保持。冠は細長く整いすぎ、正規の根元の厚み・不均一な稜線は未再現。 | REVISE |
| 前腕・手首・足 | 手首の球状感を減らし、腕へ連続した。正規より前腕の面構成が単純で、指先も丸い。接地位置の静止配置だけでは走行接地を評価しない。 | REVISE |
| 後肢 | 閉じた胴から連続する脚になったが、赤・灰の境界が単純で、正規の屈曲・筋肉の切り替わりは不足。 | REVISE |
| 尾 | 小さな独立球状の装飾を除去し、根元の隙間を修正。正規の厚い折れと重い先端に対し、まだ細く単純な曲線に見える。 | REVISE |
| 色・表面 | 赤/スレート/チャコールは保持したが、胸の灰色面が広すぎる。境界の波打ち、溝の傷状の見え方も残る。 | REVISE |

**失敗原因：** ケージで接続構造は作れたが、大きな胸の面を主要筋群へ分ける立体構成が不足した。
表面の凹線を追加しても、必要な筋肉の面の向き・厚み・重なりは自動では生まれず、線が傷のように見える部分が残った。
頭の高さの改善と胸の連続性を理由に、全体の正規一致が改善したとは断定しない。
追加の半径調整や色分けだけで完成へ進める段階ではない。

## 静止ゲート・走行

静止造形が十分近いという条件を満たさないため、**リグ変形、連続走行、3周期動画、動的接地検証には進んでいない**。
新GLBはアーマチュア・スキン・アニメーションを含まない静止候補で、v6の動画をv7として流用していない。
本バージョンの動画URLはない。新しい動画を作らない判断は今回のユーザー指定の静止ゲートに従う。
