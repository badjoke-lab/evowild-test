## One shape hypothesis per anatomical component
1. **Dorsal thorax:** high shoulder arch, less continuous straight/bulging back; retain heavy anterior mass.
2. **Scapula and pelvic lobes:** localize muscle planes to the original P anatomy and reduce ball-like convexity.
3. **Face:** narrower skull/jaw cross-sections and a lower, more directional muzzle.
4. **Crest:** lower paired blades with stronger backward rake. Front/rear spacing remains inferred because the source has no true multi-view reference.
5. **Knee/elbow:** replace ball caps with anatomically rooted, tapered tendon lofts, without changing the rig skeleton.
6. **Tail:** shorten and taper the hooked tip while preserving P's recognizable small bent tail.

Existing animation remains a **minimal gait study**, not production contact or race-quality approval.
