# Independent procedural S — v0

Open `index.html` directly in a browser; no dependencies. This is a new construction method, not an approved S model or production renderer. No existing model or animation is imported. Generated surface samples: 18,890 per pose. Four-view PNG is a software rasterization of the same model code; not a browser screenshot. The PNG's top edge crops the crest in some views. The exact authority image could not be decoded via the connector; only the written morphology contract was read. Visual deficiencies: rodlike distal limbs, rough shoulder/body connection, crest silhouette and tail unverified. Numerical check across 120 phases: all point coordinates finite, constant point count, nominal stance foot center y=.063, two segment length residual <=4.45e-16 in model units. These are coordinate checks, not actual rendered sole clearance, stance velocity, animation smoothness, browser FPS or visual approval. No real browser run yet. Main and pre-existing experimental files unchanged.
