# Tripo S review assets

This directory is for repository-visible, web-reviewable outputs from the isolated Tripo S Motion Bench.

Expected files:

- `t0-rigged-lod2.glb` — Tripo quadruped Auto Rig result from canonical unrigged LOD2
- `t0-rigged-lod4-fallback.glb` — only if a documented LOD2 import/density failure requires the controlled fallback
- `t1-steady-run.glb` — first Text to Motion result after T0 passes

Do not place speculative or mocked assets here. Every file must come from a real Tripo execution and be recorded in the review ledger.
