# S blockout deliverables

Start with CHECKPOINT.md, HANDOFF_STATE.json and output/S-blockout-v2.blend.

v1 and v2 are blockout iterations, not final/approved assets. No existing game mesh was used. The hidden S_EDITABLE_SOURCE collection retains editable cross sections; S_MODEL holds the continuous sculpt surface.

output/review/v1 and output/review/v2 each contain exactly the four supplied cameras. output/validation.json records connectivity/manifold checks, not a visual-quality pass.

Blender 4.3.2 was used. The glTF exports contain only S_MODEL. No rig, animation, textures or game integration. Main and other lanes are unchanged.
