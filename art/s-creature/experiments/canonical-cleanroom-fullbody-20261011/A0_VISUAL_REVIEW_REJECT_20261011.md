## A0の客観的な技術結果と、造形評価を分ける

- 旧メッシュの読み込みなしで独立した新規Blenderシーンを構築したのは事実。
- 41 mesh objects / 8,544 vertices / 8,210 polygon faces、Blender `.blend` と `.glb`、5方向実レンダリングをGitHub上に保存。
- そのことは**造形品質の改善を意味しない**。
- A0は細い管をつないで楕円飾りを載せた粗いブロックアウトであり、過去にREJECTした鹿型の形態から脱していない。
- 独立板パーツの接合・全身一体メッシュ・真の重なり・アーマチュア・走行は未検証。
- よって見た目の「比較的マシ」さ、完成度、ゲーム実用性のいずれも承認できない。

## 次工程 — 絶対に同じ失敗を繰り返さない

**A0をベースに楕円、管、ガウス膨張を増やす試行を禁止する。**

1. **シルエットを正しい順序で構築する**。元画像の頭の鼻先・頭冠の根元/中央/先端・首の上下輪郭・肩の峰と胸底・腰の上下・後躯・脚関節と接地点・尾芯と羽根の表裏輪郭を、画像の実ピクセル座標として採番・承認する。新しい参考イラストを作らない。
2. **先に2D形状の一致を可視化する**。原画を薄く重ねた SIDE の輪郭線・造形レイヤーごとの写像で形が近いことを証明。点状・細長い棒や単純楕円の代用はこの段階で拒否。
3. **原画に描かれる FRONT / 3/4 / BACK を同じ権威内から参照する**。未確認の奥行き形状は推測の仮仕様として明示し、5方向で矛盾ない実3D形状にする。
4. 正しいSIDEを作る前に完全3D化を宣言しない。正しい3Dが存在する前にリグ/走行/レースへ移行しない。実レンダリングは5方向提出。
5. 必要であれば造形用の専門的な人手/アーティスト作業へ切り替える。このプログラムの単純な部位プリミティブ生成を完成造形の制作手段と見なさない。
