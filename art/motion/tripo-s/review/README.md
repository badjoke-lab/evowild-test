# Tripo review session metadata

Work must write machine-readable session records here before reporting a gate complete.

Required records:

- `t0-session.json`
- `t1-session.json`

Each record should include input path, geometry LOD, Tripo rig type, prompt (for motion levels), output paths, conversion/normalization steps, visible credit consumption, and the commit SHA containing the evidence.

Do not include credentials, cookies, API keys or signed private URLs.
