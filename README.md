# EvoWild Run test

Web prototype for validating the initial EvoWild Run race presentation.

## Current scope

- 18 simultaneous racers
- S / P / E / A low-poly body morphs with deliberately different silhouettes
- client-side Three.js rendering
- Race / Follow / Tactical cameras
- heading, acceleration, blocking, lane changes and overtakes
- no server-side rendering and no live LLM calls

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

This repository is a test bed, not the final game repository.
